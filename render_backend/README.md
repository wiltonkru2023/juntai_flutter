# Backend Render

O backend canônico do Juntaí está na raiz do repositório:

- `server.js`
- `package.json`
- `package-lock.json`

A antiga cópia em `render_backend/` foi removida para impedir divergência entre duas versões da API.

No Render, mantenha o serviço apontando para a raiz do repositório e use `npm start`.
